### Introduction 

Time is a very interesting concept. Adults seemingly don't have enough of it whereas kids appear to have a lot of it. 
It saddens me to say this, but I fall in former camp. 
There's a saying that it takes 10,000 hours of practise with any skill to become a master. 
In a world of AI, I wonder if that is the still the case.

### Motivation

Why am I writing this, you may ask, it's because of a realization I've come to over the past couple of months. 
Walk with me for a bit. Over the past few months, I've done quite a lot of work, from building a simulation engine for decision making (you can check it out here https://github.com/danagbemava/athanor), an app which forces me to take a break and exercise (not public yet), an app for transcribing my meetings and generating summaries with local ai, an edtech app (full-stack), and this blog (with its open world still in development). 

All these projects, have very different stacks, and this was by design. I use personal and freelance projects as a way to learn new technologies and discover new things. All these projects have something in common; they were largely driven by AI, and I was the HITL (Human-In-The-Loop), guiding it, testing to see if it worked the way I wanted it to work, etc. At first, it was fun, but recently, one project I'm working caused me to pump the breaks a little bit. 

It's sort of like a control plane (can't say much more than that atm), and there's a very interesting part of the project; request/response/interpretation parsing. While I was cooking up the plan with superpowers plugin (very good plugin for agentic development), I read something that was a blast from the past. 


```bash
Formal grammar (ABNF-ish)
exp  = t-expr / c-expr / literal
t-expr    = "$." path
c-expr    = "$ctx." step-name "." path
path        = segment *("." segment)
segment     = key [ "[" index "]" ]
key         = 1*( ALPHA / DIGIT / "_" / "-" )       
step-name   = 1*( ALPHA / DIGIT / "_" )                
index       = "0" / (NZDIGIT *DIGIT)                  
literal     = any string not starting with "$"
```

When I read this part in the spec, I said to myself, "Man, wouldn't it be fun to implement this myself". But I didn't, I moved on. Do you want to know why? *Time* . The project I'm doing this for, based on the Functional Requirements Specification (FRS), is about 52 weeks of work. My Estimated Delivery Time (EDT), is end of June. That's crazy if you think about it but we live in a world where LLMs can write code on par, if not better than some developers.
